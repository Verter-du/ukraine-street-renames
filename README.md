# Перейменовані вулиці України / Renamed streets of Ukraine

Перелік **21 296** пар «стара назва → нова назва» вулиць у 8 184 населених пунктах України з поштовими індексами нової адреси.
Поза Києвом — перейменування з 2022 року, у Києві — з 2015 року.

Статистика й пошук: **https://indeksy.com.ua/pereimenovani-vulytsi/statystyka/**

## Файл

`pereimenovani-vulytsi.csv` — UTF-8, роздільник — кома.

| Колонка | Опис |
|---|---|
| `область` | область (для Києва — «Київ») |
| `район` | район (після реформи 2020 року) |
| `населений_пункт` | тип і назва: «м. Вінниця», «с. Рокитне» |
| `стара_назва` | назва вулиці в довіднику Укрпошти 2022 року |
| `нова_назва` | назва в довіднику 2025 року |
| `індекси_нової_адреси` | поштові індекси будинків вулиці через пробіл |
| `уточнення_написання` | `так` — це зміна написання, а не перейменування («Шевченка» → «Тараса Шевченка») |
| `джерело` | `реєстр КМДА` (Київ, 2015–2021) або `порівняння довідників Укрпошти` |

## Методика

Ми порівняли два довідники поштових індексів АТ «Укрпошта» з data.gov.ua: лютого 2022 року (для Києва — жовтня 2022) і серпня 2025 року.
Якщо в населеному пункті зникла вулиця, а з’явилася нова з тими самими номерами будинків і поштовими індексами, вважаємо це перейменуванням.
Для Києва додано офіційний реєстр вулиць КМДА з рішеннями про перейменування.

Обмеження: метод не бачить перейменувань, де змінився склад будинків, і сіл, які довідник подає без вулиць, тому реальних перейменувань більше.
Близько 900 пар — уточнення написання (колонка `уточнення_написання`).
